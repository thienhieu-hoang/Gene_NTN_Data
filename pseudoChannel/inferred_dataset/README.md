# Inferred Datasets & Pseudo-Channel Generation Overview

The `.mat` files in this directory are the outputs generated by the channel estimation inference pipelines in the [`Hest_NTN_UDA_clean/inference`](https://github.com/thienhieu-hoang/H_NTN_UDA_clean/tree/main/inference) repository, linked into `Gene_NTN_Data` via NTFS directory junctions.

---

## 1. General Workflow of Pseudo-Dataset Generation

Both [`pseudoDatasetGen_Perfect_LI.m`](../pseudoDatasetGen_Perfect_LI.m) and [`pseudoDatasetGen_Perfect_LSAttention.m`](../pseudoDatasetGen_Perfect_LSAttention.m) generate synthetic (pseudo) 5G NTN channel datasets using **Delay-Doppler Fourier Domain Adaptation (FDA)**.

```
+--------------------------+          +--------------------------+
|      Source Domain       |          |      Target Domain       |
|  Clean H_perfect (TDL-A) |          | Target Estimate (OpenNTN)|
+--------------------------+          +--------------------------+
             \                                      /
              \                                    /
               v                                  v
    +--------------------------------------------------------+
    |         Delay-Doppler Fourier Domain Adaptation        |
    |      Transfer low-frequency DD style (Delay/Doppler)   |
    |          from Target onto clean Source Phase/Grid      |
    +--------------------------------------------------------+
                               |
                               v
                     Pseudo H_perfect (GT)
                               |
        +----------------------+----------------------+
        | 5G NR Transmission Simulation & Estimation  |
        | - Transmit DM-RS pilots through pseudo grid |
        | - Add complex AWGN based on pilot SNR       |
        | - Compute LS pilot estimates (H_ls_pilots)  |
        | - 2D Linear Interpolation (H_li)            |
        | - Evaluate NMSE & Complex SSIM              |
        +---------------------------------------------+
                               |
                               v
               Saved Structured Dataset (matlabNTN.mat)
```

### Shared Capabilities:
- **Delay-Doppler FDA:** Transfers target-domain low-frequency Delay and Doppler characteristics (window size $13 \times w_w$, where $w_w \in \{3, 5\}$) onto clean source channel ground truth.
- **5G NR Simulation:** Simulates pilot transmission across $132 \text{ subcarriers} \times 14 \text{ OFDM symbols}$, injects calibrated AWGN for SNR range $[-10 \text{ dB} : 5 \text{ dB} : 15 \text{ dB}]$, performs LS estimation at pilot positions, and reconstructs 2D linearly-interpolated channel grids (`H_li`).
- **Flexible Sample Sizing & 3-Phase Index Mapping (`num_pseudo_samples`):**
  - **Phase 1 ($1 \dots N_{\min}$):** In-order 1-to-1 sequential mapping (`idx_map_source(i) = i`, `idx_map_target(i) = i`).
  - **Phase 2 ($N_{\min}+1 \dots N_{\max}$):** The larger dataset proceeds in sequential order, while the smaller dataset draws samples uniformly at random with replacement.
  - **Phase 3 ($> N_{\max}$):** Both datasets draw random samples with replacement until the requested sample count is achieved.
  - Saves `idx_map_source` and `idx_map_target` into each `matlabNTN.mat` and `sample_mapping.mat` for full reproducibility.

## 2. Key Differences Between the Two Scripts

| Feature / Aspect | [`pseudoDatasetGen_Perfect_LI.m`](../pseudoDatasetGen_Perfect_LI.m) | [`pseudoDatasetGen_Perfect_LSAttention.m`](../pseudoDatasetGen_Perfect_LSAttention.m) |
| :--- | :--- | :--- |
| **Primary Purpose** | Baseline FDA using traditional Linear Interpolation | Advanced FDA using Deep Learning model inference |
| **Target Channel Variable** | `H_li` (Target Linear Interpolated channel) | `H_LS_infer` (Model-inferred channel, e.g., LS_Attention) |
| **FDA Translation Direction** | **`H_perfect` (Source) $\rightarrow$ `H_li` (Target)** | **`H_perfect` (Source) $\rightarrow$ `H_LS_infer` (Target)** |
| **Target Dataset Source** | OpenNTN raw simulation outputs (`results/DUR300nsFix...`) | Inferred channel outputs (`inferred_dataset/.../LS_Attention`) |
| **Boundary Extrapolation Clipping (`crop_`)** | **Enabled (`true`):** Clamps un-interpolated outer boundary elements of `tgt_H_li` to the inner pilot region bounds to prevent extreme edge artifacts. | **Disabled (`false`):** Neural network models infer the entire $132 \times 14$ grid coherently, so boundary clamping is unnecessary and bypassed. |
| **Target Data Loading** | Loads `H_li` from `matlabNTN.mat` or `channel_dur_randomizedUE.mat`. | Adaptively resolves `LS_<snr>dB` folders and loads `H_LS_infer` from `inferredChannel.mat` (standardizing tensor dimensions). |
| **Default Output Directory** | `pseudoChannel/A100Perfect__DUR300LI` | `pseudoChannel/A100Perfect__DUR300LSAttention` |
| **Diagnostic Plots** | Compares Source `H_perfect`, Target `H_li`, Pseudo `H_perfect`, and Pseudo `H_li`. | Compares Source `H_perfect`, Target `H_LS_infer`, Pseudo `H_perfect`, and Pseudo `H_li`. |

```
├── pseudoDatasetGen_Perfect_LI.m       <-- Generates pseudo data via Perfect -> LI translation
├── pseudoDatasetGen_Perfect_LSAttention.m <-- Generates pseudo data via Perfect -> LS_infer translation

```
